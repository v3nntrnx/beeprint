# BeePrint

![Project Logo](assets/img/logo.webp)

A fan-made Bee Swarm Simulator crafting planner. The whole app runs in the browser; there is no backend.

## Local development

```sh
npm install
npm start
```

Other commands:

```sh
npm run build    # build dist/ only
npm run preview  # serve an existing dist/
npm run build:css
```

Set `PORT` or `HOST` to change the preview server address:

```sh
PORT=8080 npm run preview
```
